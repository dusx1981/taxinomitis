收集诊断信息

很抱歉，同学们在使用儿童机器学习网站时有时会遇到错误。
对此我深感歉意。
本页面提供了如何收集问题相关信息的方法，这些信息将帮助我快速修复问题，防止再次发生。
  1. 访问 https://machinelearningforkids.co.uk/#!/welcome?debug
    (关键是在网址末尾添加 ?debug - 这在网站的任何页面都应该有效)
  2. 如果操作成功，您会在页面顶部的菜单中看到一个新的"下载日志"选项。（如果没看到，请刷新页面直到出现）
  3. 重现问题 - 按照之前的步骤重新演示您遇到的错误
  4. 点击下载日志来下载一个文件，该文件将包含您所有操作的描述和遇到的错误信息
  5. 请将该文件发送给我：
    • 通过电子邮件，或
    • 在 Github 上创建问题，或
    • 在 支持论坛中发布消息
