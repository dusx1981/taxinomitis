## 🎯 目标

让本地服务器监听 `9000` 端口，并且当访问路径是 `/commons/2/2b/Sibirisk_Skovkat.jpg` 时，返回一张本地的图片。

---

## 🚀 三种常见实现方式

### **方案 A：最简单（Python 内置 HTTP 服务器）**

#### 步骤 1：准备文件

在本地放好目录和文件：

```bash
mkdir -p /home/dusx/projects/taxinomitis/imgs/commons/2/2b
# 下载图片
wget -O /home/dusx/projects/taxinomitis/imgs/commons/2/2b/Sibirisk_Skovkat.jpg \
  https://upload.wikimedia.org/wikipedia/commons/2/2b/Sibirisk_Skovkat.jpg
```

#### 步骤 2：启动服务器

```bash
cd /home/dusx/projects/taxinomitis/imgs
nohup python3 -m http.server 9000 > server.log 2>&1 &
```

#### 步骤 3：测试

浏览器或命令行访问：

```bash
curl -I http://localhost:9000/commons/2/2b/Sibirisk_Skovkat.jpg
```

能看到 `200 OK` 和 `Content-Type: image/jpeg` 就成功了。

---

### **方案 B：Node.js + Express（可扩展，控制更强）**

#### 步骤 1：创建项目

```bash
mkdir -p ~/image-server && cd ~/image-server
npm init -y
npm install express
```

#### 步骤 2：写 `server.js`

```js
// server.js
const express = require('express');
const path = require('path');

const app = express();
const PORT = 9000;
const ROOT_DIR = '/home/dusx/projects/taxinomitis/imgs';

app.use(express.static(ROOT_DIR));

app.listen(PORT, () => {
  console.log(`Server running at http://localhost:${PORT}`);
});
```

#### 步骤 3：运行

```bash
node server.js
```

#### 步骤 4：测试

打开：

```
http://localhost:9000/commons/2/2b/Sibirisk_Skovkat.jpg
```

---

### **方案 C：Nginx 反向代理（不下载，直接转发）**

#### 配置文件示例（`/etc/nginx/conf.d/localimg.conf`）：

```nginx
server {
    listen 9000;
    server_name localhost;

    location /commons/ {
        proxy_pass https://upload.wikimedia.org/wikipedia/commons/;
        proxy_set_header Host upload.wikimedia.org;
    }
}
```

#### 步骤 1：检查配置

```bash
sudo nginx -t
```

#### 步骤 2：重载

```bash
sudo systemctl reload nginx
```

#### 步骤 3：测试

访问：

```
http://localhost:9000/commons/2/2b/Sibirisk_Skovkat.jpg
```

会直接代理到 Wikimedia 并返回图片。
